AV MUSLIM SCHOOL — NETLIFY + SUPABASE
=====================================

The website now uses Supabase instead of PHP/MySQL, so it can run directly on Netlify.

1. Create a Supabase project.
2. Open Supabase SQL Editor and run supabase-schema.sql.
3. Create an administrator in Supabase Authentication -> Users.
4. Add that user's UUID to public.profiles with role='admin'. See README-SUPABASE.md.
5. Put the Supabase Project URL and Publishable key in supabase-config.js.
6. Push the folder to GitHub and deploy it on Netlify with publish directory '.'.

Admin page: /admin.html
Public website: /index.html

The old api.php/MySQL setup is no longer required.
